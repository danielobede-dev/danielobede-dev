## Projetos

### [UserFlow](https://github.com/danielobede-dev/Projeto-UserFlow)

Autenticação e gerenciamento de usuários, desenvolvido como avaliação técnica sobre um backend simulado.

- **Sessão:** login com JWT, interceptor no Axios, rotas protegidas e tratamento de sessão expirada.
- **Senha:** recuperação, redefinição e alteração.
- **Usuários:** CRUD com paginação sincronizada com a URL.
- **Formulários:** validação com schemas Zod, separada dos componentes de interface.
- **Experiência:** estados de carregamento, erro e lista vazia; modais com navegação por teclado e gerenciamento de foco.

React · TypeScript · Vite · TanStack Query · React Hook Form · Zod · Axios

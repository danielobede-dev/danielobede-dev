## Projetos

### [UserFlow](https://github.com/danielobede-dev/Projeto-UserFlow)

Autenticação e gerenciamento de usuários em React e TypeScript, desenvolvido como avaliação técnica sobre um backend simulado.

- Login com JWT, rotas protegidas e tratamento de sessão expirada.
- Recuperação, redefinição e alteração de senha.
- CRUD de usuários com paginação.
- Modais com navegação por teclado e gerenciamento de foco.

**Tecnologias:** React · TypeScript · Vite · TanStack Query · React Hook Form · Zod · Axios
